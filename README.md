# Anna's Song ♡

A responsive, aesthetic personal music landing page.

## Publish with GitHub Pages (free)
1. Sign in to GitHub and create a **Public** repository named `annas-song`.
2. Extract this ZIP on your phone/computer.
3. Upload `index.html` to the repository root (not inside another folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. After GitHub finishes publishing, your site URL will look like:
   `https://YOUR-USERNAME.github.io/annas-song/`

## Important about uploading songs
GitHub Pages is static hosting. It can publish this website, but it does **not** provide a private upload dashboard or permanent audio storage. To upload songs from the website and let visitors stream them, connect a storage/backend service (for example Supabase Storage) and protect the upload area with authentication. Do not put storage secret keys in `index.html`.

This starter page intentionally has no songs yet, as requested. You can add recordings after the website is published and storage is configured.
